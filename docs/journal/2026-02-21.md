## Size 9 Board Pools Created

Created all 4 board pool files for size 9 (9x9 grid, max 8 traps):

- `boards/size9/00_simple.json` -- 4 straight-line boards (cols 0, 4, 7, 8)
- `boards/size9/01_mixed_traps.json` -- 4 boards with 2-5 traps
- `boards/size9/02_super_move.json` -- 4 boards with supermove traps
- `boards/size9/03_super_move_counter.json` -- 4 boards with supermoves + counter traps

Initial validation caught 3 boards failing playability (1 in mixed_traps, 2 in super_move_counter). Root cause in all cases: traps placed diagonally from the current piece position. The validator requires strictly orthogonal adjacency for trap placement. Fixed by redesigning the affected boards with clean orthogonal sequences. All 16 boards now pass validation.
