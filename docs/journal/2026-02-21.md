## Size 9 Board Pools Created

Created all 4 board pool files for size 9 (9x9 grid, max 8 traps):

- `boards/size9/00_simple.json` -- 4 straight-line boards (cols 0, 4, 7, 8)
- `boards/size9/01_mixed_traps.json` -- 4 boards with 2-5 traps
- `boards/size9/02_super_move.json` -- 4 boards with supermove traps
- `boards/size9/03_super_move_counter.json` -- 4 boards with supermoves + counter traps

Initial validation caught 3 boards failing playability (1 in mixed_traps, 2 in super_move_counter). Root cause in all cases: traps placed diagonally from the current piece position. The validator requires strictly orthogonal adjacency for trap placement. Fixed by redesigning the affected boards with clean orthogonal sequences. All 16 boards now pass validation.

## Size 9 Pipeline Started — First Big Jump in Difficulty

Pipeline launched after size 8 completed. Size 9 is the first size where training is noticeably harder:

- **Phase 0** (simple) took 0.70M steps to clear (size 8: 0.20M — 3.5x slower)
- **Phase 1** (mixed_traps) took 1.88M steps (size 8: 1.55M) with WR bouncing 5-45% before breaking through
- **Phase 2** entered at 1.88M steps, WR dropped to 10-15% as expected

The 81-cell board (vs 64 for size 8) with 163 possible actions per step makes exploration much harder. The agent took longer to find its first win at 0% WR for the initial ~70K steps — sizes 2-8 all picked up signal faster. This is likely the scaling wall where larger boards start requiring meaningfully more training time. Estimating 5-6M steps for pool convergence (size 8: 3M).
